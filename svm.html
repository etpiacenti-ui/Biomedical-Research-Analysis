Support Vector Machines (SVMs)

Overview

Support Vector Machines (SVMs) are supervised learning models used for classification tasks. They work by finding the optimal separating boundary—called a hyperplane—that maximizes the margin between classes. SVMs are considered linear separators because, in their simplest form, they attempt to draw a straight line (in 2D) or a flat hyperplane (in higher dimensions) that best divides the data. However, many real-world datasets are not linearly separable. To address this, SVMs use kernels, which transform the data into a higher-dimensional space where a linear separator becomes possible. The kernel trick allows this transformation to happen implicitly, without ever computing the high-dimensional coordinates directly. This is why the dot product is essential: kernels rely on dot products to compute similarity in the transformed feature space. Common kernels include the polynomial kernel and the radial basis function (RBF) kernel. For example, a polynomial kernel with parameters \( r = 1 \) and \( d = 2 \) maps a 2D point into a higher-dimensional feature space that includes squared and interaction terms. Data Preparation

SVMs require labeled data because they are supervised learning models. This means each row in the dataset must include both predictor variables and a target class label. Before training the model, the data must be split into a Training Set and a Testing Set. The Training Set is used to build the model, while the Testing Set evaluates how well the model generalizes to new data. These sets must be disjoint to avoid data leakage, which would artificially inflate accuracy. SVMs also require numeric input features, so any categorical variables must be encoded.
